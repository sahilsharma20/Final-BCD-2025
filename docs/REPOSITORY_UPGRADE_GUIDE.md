# Repository Upgrade Guide

This guide explains how to apply the professional upgrade pack to the existing repository.

## 1. Back Up the Current Repository

From the parent directory:

```bash
cp -R Final-BCD-2025 Final-BCD-2025-backup
cd Final-BCD-2025
```

## 2. Copy the Upgrade Files

Copy every file and folder from the upgrade pack into the repository root. Allow replacement of:

- `README.md`
- `app.py`
- `chatbot.py`
- `requirements.txt`

The pack adds:

- `.github/workflows/ci.yml`
- `.env.example`
- `.gitignore`
- `CONTRIBUTING.md`
- `LICENSE`
- `docs/`
- `src/`
- `tests/`
- `pyproject.toml`
- `requirements-dev.txt`

## 3. Remove Files That Should Not Be Tracked

The current repository exposes generated or local runtime artifacts. Remove them from Git tracking:

```bash
git rm -r --cached __pycache__ 2>/dev/null || true
git rm --cached error.log 2>/dev/null || true
git rm --cached feedback.db 2>/dev/null || true
git rm --cached test.py 2>/dev/null || true
```

Why:

- `__pycache__/` is generated bytecode.
- `error.log` is local runtime output.
- `feedback.db` may contain user-submitted data and is environment-specific.
- `test.py` prints the API-key environment variable and is not a real test.

The replacement `.gitignore` prevents these files from being recommitted.

## 4. Remove the Duplicate Model Artifact

The model appears in both the repository root and the notebook directory. Keep the root artifact used by the Flask application and remove the duplicate:

```bash
git rm notebooks/Breast_cancer_model.pkl
```

## 5. Fix the Notebook’s Dataset Path

Replace the machine-specific path:

```python
"/Users/sahilsharma/Desktop/Final-BC/data/breast-cancer.csv.xls"
```

with a repository-relative path:

```python
"../data/breast-cancer.csv.xls"
```

Better still, use `pathlib`:

```python
from pathlib import Path

DATA_PATH = Path("..") / "data" / "breast-cancer.csv.xls"
data_frame = pd.read_csv(DATA_PATH)
```

## 6. Clean the Notebook

Before recommitting:

- Remove unnecessary full-dataframe outputs.
- Correct spelling in markdown.
- Add clear sections for objective, data, preprocessing, training, evaluation, limitations, and inference.
- Replace plain Logistic Regression with a scaling pipeline.
- Add confusion matrix, precision, recall, F1 score, and ROC-AUC.
- Restart the kernel and run all cells from top to bottom.
- Confirm that no local absolute path remains.
